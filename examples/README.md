# Example: WAIVE / MAIVE Research Audit Duel

This folder contains a worked example of the **Research Audit Protocol (ChatGPT–Gemini Duel), v1.7**.

**Task used in the example**

> I need a deep, high-quality analysis of the following topic:  
> **HOW CAN I IMPROVE THE PROPOSED WAIVE APPROACH?**  
> I am attaching the following materials:  
> `maive.pdf` (existing paper, background)  
> `waive_ottawa.pdf` (presentation of the concept of WAIVE)

**Files**

- `maive.pdf` -- Irsova, Bom, Havranek, and Rachinger (2025), "Spurious precision in meta-analysis of observational research," *Nature Communications* 16, 8454. <https://doi.org/10.1038/s41467-025-63261-0>. Open access under CC BY 4.0; used as background.
- `waive_ottawa.pdf` -- Havranek, Bom, Cala, Irsova, and Rachinger (2025), "WAIVE: Weighted Adjustment Instrumental Variable Estimator," MAER-Net Annual Colloquium, University of Ottawa, 18 October 2025; slides at <https://meta-analysis.cz/waive_ottawa.pdf>. Used as the proposed-method input.
- `AI_duel_results.docx` -- full duel output produced by running protocol v1.7 on this task.

This example shows how the protocol behaves on a real method development problem and can be used as a template for your own research audits.
